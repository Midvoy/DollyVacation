# 多利的假期 · Dolly’s Vacation

以《明日方舟》「火山旅梦」为主题的免费同人 2D 碰撞游戏。控制多利，将毛绒绒的小羊送入温泉，和同行干员一起完成 16 站假日旅程。

**[开始游戏](https://midvoy.github.io/DollyVacation/)**

![多利的假期：温泉场地与小羊](docs/screenshots/desktop.png)

## 操作方式

1. 在场地内按住鼠标或触摸屏，朝想要前进方向的反方向拖动。
2. 拖动距离决定撞击力度，松手后多利向前出发。蓄力条仅在拖动时显示。
3. 将所有小羊送入任意温泉即可通关。所有泉口通用，无需区分小羊类型。
4. 右上角可查看图鉴、暂停和打开菜单；左下角切换音乐或撤销上一次撞击。

电脑支持方向键微调、空格撞击与 Esc 暂停。手机支持横竖屏游玩，界面上下各保留一行控件。

## 玩法特点

- **16 关温泉旅程**：直线碰撞、池边反弹、连锁传力、汽水净化与护罩接力。
- **不同特性的小羊**：温泉“淘气包”阻力均衡；温泉“流浪汉”阻力较低、滑行更远；“大个子”需要先撞破护罩。
- **干员援助**：纯烬艾雅法拉净化水汽并免除当次多利落泉的额外消耗，琳琅诗怀雅放置反弹挡板，苍苔设置冷凝区。援助不限使用次数，首次使用后固定本关同行干员。
- **场地与效果图鉴**：查看温泉、汽水、洋红蒸汽、纯白水汽、冷凝区和挡板的规则。
- **活动原声**：5 首原版主界面与战斗 BGM，可切换曲目、调节音量并单曲循环。
- **星级与存档**：完成关卡、控制撞击次数及达成额外挑战获得星星；进度和设置保存在当前浏览器。

第 4 关起，多利自己落泉会额外消耗一次撞击。每关可撤销一次。图鉴中的物理特性及援助效果属于本同人游戏的玩法改编。
